> 把正在从手机里放出来的声音，实时"绕"到双耳之间——纯本地、无需 root、不联网。

SoundOrbit 是一个在设备端完成全部处理的 Android 实时环绕声工具。它不改变音源本身，只在声音到达耳机前做一次处理：让声像在两耳间往复摆动，或让声源绕着头部旋转。

**两种引擎，按需切换：**

- **零延迟模式**——把效果直接挂在系统输出混音链上，用**反相三角波调制左右声道增益**（周期、幅度、两侧/中间时间比均可调，周期还能设成范围随机）。不抓取音频、不重播，因此没有双份声音、没有回声、没有额外缓冲。
- **空间音频模式**——先内录捕获正在播放的音频流，再用 **ITD（双耳时间差）+ ILD（双耳强度差）+ 头部阴影低通 + 简易耳廓着色**把它渲染成绕头移动的双耳声场：左右、前后、上下均可辨。这是 ITD/ILD 结合频谱着色的简化双耳渲染，不是基于 HRIR 测量的真 HRTF，音质依赖个人听觉。带约 80–120 ms 延迟，需一次"录制屏幕/音频"授权。

**适合什么：** 单声道 ASMR 的绕耳聆听；给普通音乐增加声像运动；给直播、不方便下载的视频等流媒体补一层环绕感——任何"此刻正从手机里播放"的声音都能处理，不限于本地文件。

**隐私与依赖：** 应用没有 `INTERNET` 权限，代码中没有任何网络调用，也不含任何联网 SDK（依赖仅为 AndroidX 的 `annotation`、`appcompat` 与 Kotlin 标准库这类本地库）。音频全程留在设备内，不上传、不落盘、不经过任何外部服务。

## 功能特性

- **两套引擎**：轻量的系统级效果（零延迟）/ 高保真的内录空间音频（有延迟、能力更强）。
- **七种环绕方式**（空间音频模式）：
  - 伪环绕：取左 → 双耳、取右 → 双耳、双声道合成单声道 → 双耳；
  - 真环绕：立体声直接输入（L/R 各自独立绕头）、取左声道源绕头、取右声道源绕头、双声道合成单声道绕头。
- **周期随机范围**：每一轮摆动/旋转都在设定的 `[下限, 上限]` 内随机取值，相位连续不跳变；范围非法会提示重填且拒绝启动。
- **实时可视化**：声像位置、左右增益、三角波相位随音频同帧刷新。
- **双语界面**：内置简体中文与 English，设置页可切换（跟随系统 / 中文 / English），默认跟随系统。
- **保活**：前台服务、可选忽略电池优化、可选无障碍保活、快捷开关（Tile）、通知实时显示增益与参数。
- **参数自由**：程度、周期、时间比均为自由数值输入，无滑杆强加上限（输出仅在 int16 边界钳制）。

## 参数

| 参数 | 含义 | 适用 |
|---|---|---|
| 程度（摆幅） | 左右音量差的最大幅度 | 零延迟 / 伪环绕 |
| 周期（秒） | 声像摆动一个来回、或声源绕头一圈的时间 | 全部；空间音频下为旋转周期 |
| 两侧/中间时间比 | 1 = 原算法；越大两侧停留越久，越小中间停留越久 | 零延迟 / 伪环绕 |
| 起始方位（度） | 0 前 / 90 右 / 180 后 / 270 左 | 真环绕 |
| 半径（0~1） | 越小越贴头，双耳时间差/强度差越强 | 真环绕 |
| 仰角（度） | -60~60，声源在头顶还是下方 | 真环绕 |

> 真环绕只使用「周期 + 起始方位 + 半径 + 仰角」，程度与时间比对其不起作用（界面已注明）。

### 发烧友参数（设置页 · 高级）

空间音频的底层双耳渲染参数，默认收起在 **设置页 → 发烧友参数（高级）**。仅供发烧友微调，错误取值会导致定位错乱或音量异常；越界会自动钳制，也可一键「恢复默认参数」。默认值即推荐值，不改则保持原有听感。

| 参数 | 含义 | 默认 | 范围 |
|---|---|---|---|
| 最大双耳时间差 (ms) | ITD 上限，决定声场宽度与个体头围校准 | 0.7 | 0.4–1.0 |
| 声像强度差 | ILD 深度，越大定位越锐利、越小越自然 | 0.55 | 0–1 |
| 头部阴影强度 | 远侧耳高频衰减量，高频定位线索 | 0.55 | 0–1 |
| 耳廓陷波锐度 | 前后/上下可辨度的频谱陷波带宽，越接近 1 越窄越深 | 0.8 | 0.5–0.95 |

> 修改后返回主界面即生效（运行中下一帧应用）。若调乱，点「恢复默认参数」还原。

## 使用

1. 建议佩戴耳机或使用双声道设备。
2. **零延迟**：选「轻量」引擎 → 点「开启环绕声」，或添加「实时环绕」快捷开关。默认参数 `20 / 20 / 1` 即可听到效果。
3. **空间音频**：选「高级」引擎 → 点「授权音频捕获」→ 在弹窗中允许"录制屏幕/音频" → 选择七种方式之一 → 开启。
4. 需要周期随机时：勾选周期下的「周期随机范围」，填写上下限。
5. 设置页可：切换界面语言（跟随系统 / 简体中文 / English）、忽略电池优化、开启可选无障碍保活、查看/复制诊断信息，以及展开「发烧友参数（高级）」微调双耳渲染。

## 原理简述

- **零延迟 / 伪环绕**：`DynamicsProcessing` 挂在 session 0 全局混音链，按反相三角波实时改左右声道输入增益；伪环绕另先做声道复制或混合。不抓音频，故无双份声音。
- **真环绕**：`AudioPlaybackCapture` 抓其他 App 正在播放的音频副本，按 ITD（延迟线）+ ILD（远侧衰减）+ 头部阴影低通渲染双耳声场，再用 `AudioTrack` 播回。开启时静音媒体流掐掉原声（实测静音不影响捕获），播回走独立的 ASSISTANT 流，因此同样没有双份声音；捕获时排除自身 UID，避免播回声被再次捕获形成正反馈。

## 兼容性与限制

- Android 10（API 29）以上；`targetSdk 34`。
- 零延迟：挂在系统首选输出线程；通话、低延迟/直通路径不受影响。部分 ROM 不支持 session 0 全局效果时，状态栏会显示启动失败原因。
- 空间音频：需一次"录制屏幕/音频"授权；只能捕获允许被捕获的 App（多数音乐/视频 App 默认允许，部分版权 App 禁止）；蓝牙耳机同样可用；约 80–120 ms 延迟。
- 系统无障碍里的"单声道音频"是在输出端合并，会抹掉左右摆动，不适用本方案。

## 构建

```bash
./gradlew :app:assembleDebug
```

产物在 `app/build/outputs/apk/debug/`。需要 Android SDK（API 34）与 JDK 17。工程使用 Gradle Wrapper + AGP 8.6.1，`compileSdk 34`、`minSdk 29`、`targetSdk 34`。

IDE 直接打开工程根目录即可（Android Studio）。
